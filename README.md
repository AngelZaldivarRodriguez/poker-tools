# Poker Tools

Herramientas estáticas (HTML/CSS/JS sin build) para estudiar cash 6-max:

- `trainer.html` — Preflop Trainer: drills de aperturas y 3-bet/call/fold con repetición espaciada, contra reloj.
- `chart.html` — Chart de aperturas, 3-bet por posición, notas de postflop, pot odds y AoF.

Se sirve tal cual con GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
